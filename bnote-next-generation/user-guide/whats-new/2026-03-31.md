# What's New - 2026-03-31

## In One Minute

BNote Next Generation now has a dedicated non-technical user guide with migration support and clear release update communication.

## What Changed

- New multilingual user-guide structure is available.
- Core migration pages now explain old BNote to Next Generation in plain language.
- A reusable "What's New" format is introduced for recurring user communication.

## Why It Matters For Organizers

You can onboard admins and members faster, with fewer repeated explanations and less uncertainty during migration.

## Do This Now

1. Share your language home page from `user-guide/i18n/<lang>/index.md`.
2. Ask the people who run your band workflow to read Quick Start and migration pages.
3. Use this update format to communicate future product changes.

## If You Used Old BNote

- Keep familiar wording in your team notes for the first weeks.
- Add links to "Old vs Next Generation" for every rollout message.
