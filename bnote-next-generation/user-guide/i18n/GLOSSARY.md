# User Guide Glossary

Use these canonical terms across all user-guide languages.

| Concept | EN | DE | ES | FR |
| --- | --- | --- | --- | --- |
| User Guide | User Guide | Benutzerhandbuch | Guia de usuario | Guide utilisateur |
| What's New | What's New | Was ist neu | Novedades | Nouveautes |
| Migration Guide | Migration Guide | Migrationsleitfaden | Guia de migracion | Guide de migration |
| Quick Start | Quick Start | Schnellstart | Inicio rapido | Demarrage rapide |
| Attendance response | Attendance response | Teilnahme-Rueckmeldung | Respuesta de asistencia | Reponse de presence |
| Organizer | Organizer | Organisator:in | Organizador | Organisateur |
| Troubleshooting | Troubleshooting | Fehlerbehebung | Resolucion de problemas | Depannage |
| Old BNote | old BNote | altes BNote | BNote antiguo | ancien BNote |
| Next Generation | Next Generation | Next Generation | Next Generation | Next Generation |

## Style Notes

- Prefer short sentences.
- Use action-first wording.
- Use the same section order for critical pages.
