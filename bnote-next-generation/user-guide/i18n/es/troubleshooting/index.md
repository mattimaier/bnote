# Resolucion de problemas

## Situaciones frecuentes

### "No todos responden"

- Verifica la fecha limite.
- Envia un recordatorio claro y breve.
- Confirma que todos saben donde responder.

### "El equipo se pierde con cambios"

- Usa una sola guia de referencia.
- Compara flujo antiguo y nuevo.
- Revisa novedades semanales.
