# Novedades y guia de migracion

Esta pagina explica los cambios recientes y como migrar desde BNote antiguo de forma segura.

## Ideas clave

- Next Generation mantiene compatibilidad con la base de BNote.
- El cambio principal esta en usabilidad y claridad.
- Puedes migrar proceso por proceso.

## Plan simple

1. Elige un proceso semanal (por ejemplo, asistencia de ensayo).
2. Usalo dos semanas en Next Generation.
3. Comparte una mini checklist con responsables.
4. Migra el siguiente proceso.

## Habito semanal de novedades

1. Lee la ultima nota en [Indice de Novedades](../../../whats-new/index.md)
2. Comparte dos cambios importantes con el equipo
3. Aplica una mejora en el siguiente ciclo
