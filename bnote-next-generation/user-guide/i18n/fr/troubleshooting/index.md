# Depannage

## Situations frequentes

### "Tout le monde ne repond pas"

- Verifie la date limite.
- Envoie un rappel court et clair.
- Verifie que tout le monde sait ou repondre.

### "L'equipe se perd avec les changements"

- Utilise une seule reference de guide.
- Compare ancien et nouveau flux.
- Suis les nouveautes hebdomadaires.
