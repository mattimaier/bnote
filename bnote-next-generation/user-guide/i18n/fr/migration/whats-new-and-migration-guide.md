# Nouveautes et guide de migration

Cette page explique les changements recents et comment migrer depuis ancien BNote en securite.

## Points cles

- Next Generation garde la compatibilite avec la base BNote.
- Le principal changement est l'ergonomie et la clarte.
- Tu peux migrer processus par processus.

## Plan simple

1. Choisir un processus hebdomadaire (par ex. presence aux repetitions).
2. L'utiliser deux semaines dans Next Generation.
3. Partager une mini checklist avec les responsables.
4. Migrer le processus suivant.

## Routine hebdomadaire

1. Lire la derniere note dans [Index des Nouveautes](../../../whats-new/index.md)
2. Partager deux points importants avec l'equipe
3. Appliquer une amelioration au prochain cycle
