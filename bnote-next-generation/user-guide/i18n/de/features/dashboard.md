# Dashboard: dein taegliches Steuerzentrum

Das Dashboard hilft dir, in unter 2 Minuten die naechste wichtige Aktion zu sehen.

## Was du dort siehst

- Begruessung und Uebersicht
- kommende Termine
- Termine mit offenen Teilnahme-Rueckmeldungen
- Admin-Hinweise (falls du Admin bist)

## Tagesroutine (2 Minuten)

1. Dashboard oeffnen
2. Termine mit offenen Rueckmeldungen zuerst pruefen
3. Dringendsten Termin oeffnen
4. Falls noetig eine gezielte Erinnerung senden

## Warum das hilfreich ist

Ohne Dashboard springst du oft zwischen vielen Seiten und Chats.
Mit Dashboard ist die naechste Aktion schnell klar.

## Typische Fehler vermeiden

- Alle Module pruefen, bevor offene Rueckmeldungen geklaert sind
- Lange Updates senden, bevor Teilnahme-Status klar ist
- Admin-Hinweise ignorieren
