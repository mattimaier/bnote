# Troubleshooting

This section helps non-technical users solve common issues quickly.

## Common Situations

### "Some members did not respond"

- Check response deadlines.
- Send one clear follow-up reminder.
- Confirm members know where to respond.

### "People miss updates"

- Keep one channel for official updates.
- Add event comments with short action-focused messages.
- Link to the relevant guide page in your update.

### "Our team is unsure about the new app"

- Start with one routine workflow.
- Share old-vs-new mapping from the migration guide.
- Collect feedback after one full weekly cycle.

## Support Checklist

Before escalating:

1. What exact action failed?
2. Who is affected (all users or specific users)?
3. Is this a new issue or ongoing?
4. Which guide page did you already follow?
