# How the app is structured

This page explains the structure of BNote Next Generation in simple terms.

## The 3 main areas

1. **Dashboard**: your daily starting point
2. **Feature areas**: contacts, events, participation, tasks, comments, calendar
3. **Settings/Profile**: your preferences and account details

## What to open first each day

Start with the dashboard, because it shows:

- upcoming events
- events that still need responses
- action hints for admins

## How to think about navigation

- The sidebar is your map.
- Each feature area focuses on one band-management job.
- Event details are where most coordination happens.

## If you are non-technical

You do not need to understand system internals. Treat the app like a checklist tool:

1. Open dashboard
2. Check what needs action
3. Open the relevant event
4. Request or review participation responses
5. Send one clear update
