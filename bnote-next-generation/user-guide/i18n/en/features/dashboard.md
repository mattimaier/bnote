# Dashboard: your daily control center

The dashboard helps you decide what to do next in under 2 minutes.

## What you see

- greeting and overview context
- upcoming events
- events that still need attendance responses
- admin action hints (if you are admin)

## Daily routine (2 minutes)

1. Open dashboard
2. Check events needing response first
3. Open the most urgent event
4. Send one follow-up reminder if needed

## Why this is useful

Without the dashboard, organizers often jump between many pages and chats.
With the dashboard, your next action is visible quickly.

## Typical mistakes to avoid

- Checking all modules before checking urgent responses
- Sending long updates before clarifying attendance status
- Ignoring admin action hints
