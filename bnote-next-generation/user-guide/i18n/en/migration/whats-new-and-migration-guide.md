# What's New & Migration Guide

This page explains recent improvements and how to move safely from old BNote workflows.

## Read This First

- BNote Next Generation keeps core BNote behavior and data compatibility.
- The biggest differences are in usability, navigation, and clarity.
- You can migrate workflow by workflow, not all at once.

## What Is New In Next Generation

- Cleaner screens for daily actions
- Better mobile usage for members and admins
- Easier visibility of who has responded and who has not
- Better support for scheduled reminder communication

## Migration Approach (Simple)

1. Pick one recurring process (for example: rehearsal attendance).
2. Run it for two weeks only in Next Generation.
3. Keep a short checklist for your organizers.
4. Move the next process after the first one is stable.

## If You Used Old BNote

- Keep old terminology in your team communication at first.
- Add "new location" hints in your internal notes.
- Focus on faster routine tasks and fewer follow-up messages.

## "What's New" Update Habit

For each release update:

1. Read the latest update in [What's New Index](../../../whats-new/index.md)
2. Share two key points with your internal coordinators
3. Apply one improvement in your next band cycle
