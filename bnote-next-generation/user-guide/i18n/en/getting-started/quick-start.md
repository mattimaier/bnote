# Quick Start (15 Minutes)

This page gets your band running fast in BNote Next Generation.

## Goal

In 15 minutes, you will:

1. sign in and check your profile
2. create or open an event
3. request attendance responses
4. verify reminders and communication

## Step 1 - Sign in and profile check

- Log in with your existing account.
- Open your profile and verify name, email, and language.
- Save changes before moving on.

## Step 2 - Create or review an upcoming event

- Open your event or rehearsal area.
- Confirm date, time, place, and participants.
- Add missing members if needed.

## Step 3 - Ask for responses

- Use participation/response actions to ask members to confirm.
- Set a clear answer deadline.
- Monitor open responses.

## Step 4 - Keep everyone informed

- Add a short comment or update for all participants.
- Confirm reminder settings if you are admin.
- Check that your key members know where to respond.

## If You Used Old BNote

- You still do the same core work (events, contacts, participation).
- The new app improves clarity and navigation.
- Start with one weekly routine, then migrate the rest.
